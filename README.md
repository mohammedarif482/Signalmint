# Signalmint

> The AI Creative Performance & Budget System

SignalMint continuously monitors your top 25 competitors, isolates crown-winning ad hooks, and deploys 24/7 automated budget stop-loss guardians.

## Features
- **100% Light Theme Only:** Base canvas `#E7E6FB`, `#FAFAFD`, and `#DCDAFD`. Primary ink `#1A0042`, accent tints `#4D0181` and `#1516A8`.
- **Sticky Kinetic HUD:** Real-time status indicator & glassmorphic navigation.
- **Asymmetric 2-Column Hero:** Editorial kinetic typography with GSAP entrance timeline and floating interactive glass telemetry card.
- **Dual-Agent Autonomous System (Oddity Pinned Split):**
  - **SCOUT:** Competitive Creative Intelligence, 25+ competitor tracker, Crown Winner ad detector, 3-sec hook X-ray.
  - **ATLAS:** 24/7 Autonomous Budget Guardian, 30-min bleed protection, automated health scores (0-100), dynamic capital redistribution.
- **Crown Winners Showcase:** GSAP horizontal scrub reel displaying hook rates, script breakdowns, and retention curves.
- **The Unfair Advantage Matrix:** 3-column benchmark comparison matrix.
- **Live Telemetry Simulator:** Interactive budget modeling & real-time bleed interception sandbox.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Smooth Scroll:** Lenis
- **Motion & Choreography:** GSAP + ScrollTrigger + Framer Motion
- **Icons:** Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
